# Source and packaging changes

- MIM: author-specified SparK source; selected the existing `pretrain_nn.py` U-Net entry. Removed host-specific nnU-Net search paths and forced GPU selection. Replaced data/checkpoint paths with local configuration paths. The TIFF loader ignores metadata/preview files. Network and objective retained.
- Instances: original connected-component / watershed kernels retained. Added a portable CLI; production connected-component and later validation probability-seed methods remain separate. Historical mixed-cell hard-coded driver scripts were not promoted to production entry points.
- Contacts: the current version computes distances from the supplied label geometry at ZYX sampling 50/4/4 nm. The earlier 16-nm XY dilation and paired-radius outputs have been removed at the author's request. New outputs use `as_provided_labels_v1`; adapters reject incompatible prior runs. Earlier production tables, figures, and manuscript results were not recalculated or modified by this code update.
- Point clouds: supplied unified_ssl implementation's non-momentum branch renamed `SimSiam`; unused EMA branch removed without changing the active loss, projector, predictor or stop-gradient calls. Entrypoints renamed `train_simsiam.py` / `extract_embeddings.py`; HGG-specific configuration drops unrelated image-segmentation fields. HDF5 input path and last-16-object holdout made explicit. Data-loader workers reduced from 32 to 4 for the release example; optimizer and learning-rate defaults retained. Iterator syntax modernized. Added a separately labelled mesh-to-pointcloud utility, not a reconstruction of the historical corpus.
- Data: representative intensity crops from the pre-existing 16-nm scale; exact crop provenance is in JSON sidecars. Existing mesh coordinates and file bytes preserved; new archives restricted to final cohort IDs. No original source files, labels, models or results were altered.
- Morphometric measurement code omitted at the author's instruction. Model weights are not included in this newly specified package.
- Documentation: the main README is a concise usage overview; full data contracts, tests, and implementation details remain in module guides and `docs/`. Public synthetic tests and the threshold-row-to-primary-table adapter are maintained alongside the current measurement protocol.

Original-source hashes and source locations are retained in the private/internal packaging record. Any copied upstream implementation requires preservation of its original notices and author review of redistribution/licensing before upload. No new licence is assigned by this operation.
